# Module 02: Titles

The title is the part of your listing that does the most work. It is what search matches, and on a phone it is often the only text a buyer reads before tapping (or scrolling past).

A good title is not clever. It is the words a buyer would type, in the order they would type them, with nothing untrue and nothing wasted.

Every prompt in this module starts from your Listing Brief (Module 01). If you have not made one yet, do that first. It takes two minutes and it is the difference between a title with facts and a title with guesses.

---

## Title lengths and rules at a glance

Limits change. We checked these in September 2026, but always **check the current rule in the platform's help pages** before relying on it. Module 12 has the full cheatsheet with sources and dates.

| Platform | Title length (at the time of writing) | Other title rules | Notes |
|---|---|---|---|
| eBay UK | 80 characters | Use the space for relevant keywords such as brand, model and variant. No unrelated brand names | Front-load brand and item type |
| Vinted | No confirmed limit. Check the listing form | Vinted relies on its own fields (brand, size, colour, condition, material) for filters | Short, clear titles read best in the app |
| Depop | One combined description field (commonly quoted as 1,000 characters) | The opening words act like a title in search and in the feed | Treat your first line as the title |
| Etsy | 140 characters | Readable phrase first, not a list of keywords | Keep it short enough to read at a glance |
| Amazon UK | 75 characters for all categories except media, from 27 July 2026 | No ! $ ? _ { } ^ ¬ ¦ unless part of the brand name. No word more than twice (small words like "and" excepted). New 125-character "Item Highlights" field | Amazon may rewrite titles that break the rules |
| TikTok Shop UK | Minimum 15 characters. Maximum commonly quoted as 255 characters | No promotions ("20% off"), no seller name or web address, no mention of TikTok or other platforms, no symbols or special characters | Accurate and concise: product type, material, key features, quantity, size |

**Spaces and punctuation count as characters** on every platform. A title that is one character over will be rejected or cut off.

## Title formulas by category

Use these as a starting order. Swap the order if buyers in your niche search differently (for example, collectors often search set number first).

### eBay UK (80 characters)

| Category | Formula |
|---|---|
| Clothing | Brand + Gender + Item type + Key style + Colour + Material + Size + (Fit or detail) |
| Shoes | Brand + Model + Gender + Shoe type + Colour + UK size + (Material) |
| Electronics | Brand + Model name + Model number + Capacity or spec + Colour + (Unlocked / Boxed) |
| Books | Title + Author + Format + (Edition, only if confirmed) + Year of this copy |
| Vinyl and CDs | Artist + Title + Format + (Label, catalogue number) + (Pressing, only if confirmed) |
| Homeware | Brand or maker + Range or pattern + Item type + Colour + Size or capacity |
| Toys and collectables | Brand + Name or set number + Series + (Complete / Boxed) + Year if printed |

### Vinted and Depop (short, style-led)

| Category | Formula |
|---|---|
| Clothing | Brand + Item type + Colour + Size + (One style word buyers use, e.g. "oversized") |
| Shoes | Brand + Model + Colour + UK size |
| Accessories | Brand + Item type + Colour + (Material) |
| Homeware and books (Vinted) | Brand or title + Item type + Key detail |

### Etsy (140 characters, readable first)

| Type | Formula |
|---|---|
| Handmade | What it is in plain words + Main material + Key feature + (Personalisation) + (Who or what it is for) |
| Vintage | Era (only if you can support it) + Brand or maker + Item type + Material + Colour |
| Craft supplies | Material + Item type + Size or quantity + Colour |

### Amazon UK (75 characters, all categories except media)

| Type | Formula |
|---|---|
| Most products | Brand + Product type + Key feature + Size or quantity + Colour |
| Media (books, music, video) | Follow the category style guide. Media is excluded from the 75-character change |

### TikTok Shop UK

| Type | Formula |
|---|---|
| Most products | Brand + Product type + Material + Key feature + Size, colour or quantity. Plain words, no symbols, no promotions, no platform names |

## Title mistakes that cost you

- **Hype words:** "Stunning", "Amazing", "Must have", "L@@K". They take up space and buyers do not search for them.
- **Unsupported claims:** "Rare", "Vintage", "Genuine", "Limited edition", "Brand new" when it is not.
- **Other brands as keywords:** "Not Zara" or "Zara style" is keyword spam and can break platform rules. List only the actual brand.
- **US words:** "pants" (UK buyers search "trousers"), "sweater" (UK: "jumper"), "purse" (UK: "handbag"), "sneakers" (UK: "trainers").
- **Size confusion:** say "UK 8" for shoes, not just "8". For clothes, say what is on the label.
- **Repeating words:** "Dress Midi Dress Summer Dress" does not help and on Amazon it breaks the rules.

## The T prompts

Each prompt ends with the same short safety block so you can see exactly what the AI has been told.

### T1 eBay UK title (80 characters)
**Use it when:** you are listing on eBay UK and want a title that uses the space well without padding.
**Paste this:**
```text
Write 3 eBay UK listing titles for the item in my Listing Brief below.

How to build them:
- Put the words a UK buyer would search first: brand, then item type, then the most important details (model, size, colour, material).
- Use this order unless the brief suggests a better one for this category: [FORMULA, OR WRITE "YOUR CHOICE"]
- Aim for 70 to 80 characters. Never go over 80 characters including spaces.
- After each title, show the exact character count.

Rules:
1. UK English and UK sizes (e.g. "UK 8" for shoes, "trousers" not "pants").
2. Use ONLY facts in my Listing Brief. If a key search word is missing (e.g. model number), write [CHECK: model number] in the title and tell me.
3. No hype words (stunning, amazing, must have, wow, L@@K), no exclamation marks, no emoji, no capital letters for whole words.
4. No misleading claims: do not use rare, vintage, genuine, new, limited edition, or a date unless the brief supports it.
5. Do not mention any brand other than the item's actual brand.
6. Do not repeat words.

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]
```
**What good output looks like:**

For a grey Next wool-blend jumper, size 12, light bobbling under the arms:

> 1. Next Womens Grey Wool Blend Crew Neck Jumper Size 12 Long Sleeve Knit Pullover (79)
> 2. Next Grey Wool Blend Jumper Womens UK 12 Crew Neck Knitted Pullover Long Sleeve (79)
> 3. Next Womens Wool Blend Jumper Grey Size 12 Crew Neck Soft Knit Casual Pullover (78)

Notice: no "bobbling" in the title (flaws belong in the description and condition), no "vintage", no "stunning".

**Check before you post:**
- Count the characters yourself or paste the title into the eBay form. AI tools often miscount.
- Every word must be true. "Crew neck" only if it is a crew neck.
- Pick the version that starts with what your buyers type first. For fashion that is usually brand.
- Do not add "free postage" to the title if eBay already shows it. It wastes space.

### T2 Vinted title
**Use it when:** you are listing clothes, shoes, accessories or homeware on Vinted.
**Paste this:**
```text
Write 3 Vinted titles for the item in my Listing Brief below.

How to build them:
- Short and clear: brand, item type, colour, size, plus one style word buyers use if it is true (e.g. oversized, cropped, high waisted, wide leg).
- Aim for about 40 to 60 characters so it is readable in the app. Keep under the limit shown on the Vinted listing form (check it when you list).
- Show the character count after each.

Rules:
1. UK English and UK sizes.
2. Use ONLY facts in my Listing Brief. Write [CHECK: ...] if something important is missing.
3. No hype words, no emoji, no exclamation marks, no "bundle deal" or pricing words in the title.
4. No misleading claims (rare, vintage, genuine, new) unless the brief supports them.
5. No other brand names (no "Zara style", "not Nike").

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]
```
**What good output looks like:**

For a pair of black Levi's 501 jeans, W30 L32, faded at the knees:

> 1. Levi's 501 Black Straight Leg Jeans W30 L32 (42)
> 2. Levi's 501 Jeans Black W30 L32 Button Fly (41)
> 3. Black Levi's 501 Straight Jeans W30 L32 (39)

**Check before you post:**
- Brand, size and colour also go in Vinted's own fields. Fill those in too: they power the filters buyers use.
- Only say "button fly" if you have checked.
- Keep the fading in the description and condition, not the title.

### T3 Depop opening line (acts as the title)
**Use it when:** you are listing on Depop, where the first words of the description do the job of a title.
**Paste this:**
```text
Write 3 options for the opening line of a Depop listing for the item in my Listing Brief below. This line works as the title, so it must say what the item is straight away.

How to build it:
- Start with brand and item type, then colour, size and one or two style words buyers really search for (e.g. y2k, 90s, cottagecore, grunge) ONLY if they honestly fit the item and my brief.
- Keep each option to one short line, under about 60 characters.
- Plain text, no hashtags in this line (hashtags go at the end of the description, see Module 04).

Rules:
1. UK English and UK sizes.
2. Use ONLY facts from my brief. Write [CHECK: ...] for missing key facts.
3. An era word (90s, y2k, 70s) must be backed up by the brief. If the brief does not support it, do not use it and tell me.
4. No hype words, no emoji spam, no exclamation marks.
5. No other brand names.

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]
```
**What good output looks like:**

For a brown suede Topshop jacket, size 10, tag style suggests late 1990s (not confirmed):

> 1. Topshop brown suede jacket, size 10, 90s style (42)
> 2. Brown suede Topshop jacket UK 10, button front (44)
> 3. Topshop suede jacket in brown, size 10, boxy fit (44)

Note: "90s style" is used rather than "90s", because the era is not confirmed. If you can confirm it, change it.

**Check before you post:**
- "Style" words (y2k, 90s) should describe the look honestly. Do not claim a date you cannot support.
- Make sure the opening line matches what is in the photos.
- Depop's own advice is short, clear descriptions with measurements and signs of wear. Your opening line should set that up.

### T4 Etsy title (140 characters)
**Use it when:** you are listing a handmade, vintage or craft supply item on Etsy.
**Paste this:**
```text
Write 3 Etsy titles for the item in my Listing Brief below.

How to build them:
- Start with a clear, readable phrase that says exactly what the item is, as a person would say it. Then add the most important details: main material, key feature, size, colour, and personalisation if offered.
- Keep under 140 characters including spaces, and ideally under 15 words.
- Do not stuff: each phrase should add a new detail, not repeat the same idea in different words.
- Show the character count and word count after each.

Rules:
1. UK English (personalised, colour, jewellery).
2. Use ONLY facts in my Listing Brief. Write [CHECK: ...] for anything missing.
3. No hype words, no "best", no "perfect gift" unless the brief states who it is designed for.
4. "Vintage" only if the brief says the item is at least 20 years old and I can support that. Check Etsy's current vintage rules.
5. No health or wellbeing claims (e.g. calming, healing, anxiety relief).
6. No other brand names or trademarked characters.

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]
```
**What good output looks like:**

For a handmade sterling silver stacking ring, hammered finish, sizes J to Q:

> 1. Hammered Sterling Silver Stacking Ring, Handmade Thin Band, UK Sizes J to Q (74 characters, 13 words)
> 2. Sterling Silver Stacking Ring with Hammered Finish, Handmade Thin Band (70 characters, 10 words)
> 3. Handmade Hammered Silver Ring, Thin Sterling Stacking Band, Minimalist (70 characters, 9 words)

**Check before you post:**
- "Sterling silver" is a legal description. Only use it if it is 925 silver, and check whether your item needs hallmarking in the UK.
- Etsy titles do not need to use all 140 characters. Clear beats long.
- Put your extra keywords in the 13 tags (Module 04), not the title.

### T5 Amazon UK title and Item Highlights
**Use it when:** you are a brand or seller creating an Amazon UK product listing.
**Paste this:**
```text
Write an Amazon UK product title and an Item Highlights line for the product in my Listing Brief below.

Title:
- Order: Brand, product type, key feature, size or quantity, colour (unless my category style guide says otherwise).
- 75 characters or fewer including spaces (the limit for all categories except media from 27 July 2026; I will check the current rule and my category style guide).
- Capitalise the first letter of each word except short words (and, or, for, the, with, in, of).
- Numbers as digits (2, not two). Units spelled clearly (cm, ml, kg).
- Show the character count.

Item Highlights (if my category has this field):
- Up to 125 characters. Extra useful details (material, use, size range) that did not fit in the title. No repetition of the title.
- Show the character count.

Rules:
1. UK English.
2. Use ONLY facts in my brief. Write [CHECK: ...] for anything missing.
3. No special characters ! $ ? _ { } ^ ¬ ¦ (unless part of the brand name) and no emoji.
4. Do not use the same word more than twice (short words like "and", "with", "for" excepted).
5. No promotional or subjective words (best, top quality, hot item, free delivery, sale, 100% guaranteed).
6. No health, medical or environmental claims unless my brief gives the evidence and I confirm it is allowed.
7. No other brands.

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]
```
**What good output looks like:**

For a set of 4 invented "Hartwell Home" linen napkins, 45 cm square, sage green:

> **Title:** Hartwell Home Linen Napkins Set of 4, 45 x 45 cm, Sage Green (61)
> **Item Highlights:** 100% linen, machine washable at 40 degrees, hemmed edges, for everyday dining or occasions (98)

**Check before you post:**
- Check the style guide for your exact category in Seller Central. Title rules differ between categories.
- "100% linen" and washing temperature must come from your product spec, not the AI.
- Amazon may rewrite titles that do not meet its rules. Reading your title back as a buyer on a phone is the best test.

### T6 TikTok Shop UK product title
**Use it when:** you are listing a product in TikTok Shop UK.
**Paste this:**
```text
Write 3 TikTok Shop UK product titles for the product in my Listing Brief below.

How to build them:
- Brand, product type, material, the one or two features that matter most, then size, colour or quantity.
- Clear enough to understand at a glance on a phone. At least 15 characters. Aim for 60 to 100 characters, and stay within the current TikTok Shop limit (I will check it in Seller Center).
- Show the character count.

2. Use ONLY facts in my brief. Write [CHECK: ...] for anything missing.
3. No hype or trend words (viral, best seller, must have), no emoji, no symbols or special characters, no exclamation marks, no capital letters for whole words.
4. Do not mention TikTok or any other platform, my shop name or any web address.
5. No claims that the product cures, treats, prevents or relieves anything, and no weight loss claims.
6. No price, discount or urgency words (sale, 20% off, only 2 left, today only).
7. No other brands or trademarked names.

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]
```
**What good output looks like:**

For an invented "Brookfield" stainless steel insulated water bottle, 750 ml, matte black:

> 1. Brookfield Stainless Steel Insulated Water Bottle 750ml, Leakproof Lid, Matte Black (82)
> 2. Brookfield 750ml Insulated Water Bottle, Double Wall Stainless Steel, Black (75)

**Check before you post:**
- "Leakproof" and "keeps drinks cold for 24 hours" style claims must be in your product spec and tested. Leave them out if not.

### T7 Title tester: which version is clearest?
**Use it when:** you have 2 to 5 title ideas and want an honest, buyer's-eye comparison.
**Paste this:**
```text
I am choosing a title for a [PLATFORM] UK listing. Here are my options and my Listing Brief.

For each title:
1. Count the characters including spaces. Say if it is over [LIMIT] characters.
2. Say what a UK buyer would most likely type to find this item (give 3 short example searches). Tick which searches each title matches.
3. Flag anything not supported by the brief, any hype, any repeated words, any US spellings or sizes.
4. Say what a buyer sees in the first 40 characters (roughly what shows on a phone before it cuts off). Is it clear what the item is?

Then recommend one and explain why in two lines. Do not invent new facts. If you suggest an improved version, use only facts from the brief.

UK English.

Titles:
[PASTE TITLE 1]
[PASTE TITLE 2]
[PASTE TITLE 3]

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]
```
**What good output looks like:**

For three eBay titles for a Nintendo Switch Lite:

> | Title | Characters | Matches "switch lite grey" | Matches "nintendo switch lite console" | First 40 characters clear? | Issues |
> |---|---|---|---|---|---|
> | 1 | 78 | Yes | Yes | Yes | None |
> | 2 | 84 | Yes | No | Yes | Over 80 characters |
> | 3 | 61 | Yes | Yes | No, starts with "Amazing condition" | Hype word, wasted space |
>
> **Recommendation:** Title 1. It leads with brand and model, fits the limit and matches all three example searches.

**How to test for real:** after you post, search the platform the way a buyer would (use the app, not your seller view) and see if your listing appears for the obvious searches. If it does not, compare your title with sold listings for similar items and look at which words they share. Change one thing at a time so you know what made the difference.

**Check before you post:**
- The AI's guess at buyer searches is a starting point. The platform's own search suggestions (start typing in the search bar) are a better guide.
- A recommendation is only useful if the winning title is 100% accurate.
- Character counts from AI tools can be off by a few. Check in the listing form.

### T8 Title fixer: too long, too vague or too spammy
**Use it when:** you already have a title (maybe from an old listing or a generic AI tool) and it needs fixing.
**Paste this:**
```text
Fix this [PLATFORM] UK listing title. The limit is [LIMIT] characters (I will double-check the current limit in the platform's help pages).

My current title:
[PASTE TITLE]

My Listing Brief:
[PASTE YOUR LISTING BRIEF HERE]

Do this:
1. List what is wrong with it: over the limit, hype words, repeated words, US spellings or sizes, unsupported claims, other brand names, wasted words.
2. Write 2 fixed versions, each within the limit, with character counts.
3. Only use facts from the brief. If the old title claims something the brief does not support, remove it and tell me what you removed and why.

UK English. No hype, no emoji, no exclamation marks.
```
**What good output looks like:**

For the old eBay title "STUNNING!!! Vintage RARE Mulberry Style Leather Purse Bag Bag Brown L@@K" on a brown leather handbag with no brand label:

> **What is wrong:** Capitals and exclamation marks. "Stunning" and "L@@K" are hype. "Vintage" and "rare" are not supported by the brief. "Mulberry Style" names another brand, which is not allowed. "Bag" is repeated. "Purse" is a US word for a handbag.
> **Fixed:**
> 1. Brown Leather Handbag Womens Shoulder Bag Top Zip Two Handles Medium Size (73)
> 2. Womens Brown Leather Shoulder Handbag with Top Zip, Twin Handles, Medium (72)
> **Removed:** "Mulberry Style" (another brand's name, a keyword and trademark risk), "Vintage" and "Rare" (not in the brief).

**Check before you post:**
- If the item has no brand label, do not guess one. "Unbranded" is fine and honest.
- Update the description to match the new title so they tell the same story.
- If the old title was on a live listing, check whether editing it affects any watchers or offers on that platform.

## Title checklist (use for every listing)

- [ ] Starts with what a buyer would type first (usually brand, then item type)
- [ ] Within the platform's current limit, counted in the listing form
- [ ] Every word is true and supported by the brief
- [ ] UK spelling and UK sizes
- [ ] No hype words, no emoji, no capitals for whole words
- [ ] No other brands, no "style of" or "not X"
- [ ] No flaws in the title (they go in the description and condition fields)
- [ ] Matches the photos
