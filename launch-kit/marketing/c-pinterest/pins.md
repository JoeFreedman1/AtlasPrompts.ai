# Pinterest pins PIN01 to PIN30

Written for Well Listed, 29 September 2026. Keywords from `research/keywords-hashtags.md` (Pinterest section). One pin per `## PINxx:` heading, fields as bullet lines, so a script can parse them.

Notes for every pin:
- **Size:** 1000 x 1500 pixels (2:3). Use the Canva "WL master: pin" template (see `marketing/j-tools/free-tools-and-10-minute-workflow.md`).
- **Brand:** Ink `#1F2A44`, Cream `#FAF6EF`, Kraft `#C9A27E`, Sold Green `#1E7F55`, Label Yellow `#F2C84B`, Returns Red `#C4453B` (sparingly). Headings Archivo 800 (or Montserrat ExtraBold), body Inter 600. Small "Well Listed" text logo with a green tick at the bottom of every pin.
- **Links** are site-relative. Before scheduling, put the live site address in front (for example `https://<your-site>/blog/how-to-write-an-ebay-title-uk.html`). Only schedule a pin once its blog post is live.
- **Honesty:** every example listing, price and message on a pin is invented and carries a small "Example" label. Any platform limit shown on a pin carries the small line "Check the current rule in the platform's help pages". No marketplace logos, no faces, no sales or income claims.
- **Boards:** "eBay Selling Tips UK", "Vinted Selling Tips", "Listing Templates and Prompts", "Reseller Organisation".
