# Ready-to-post images

One folder per post (P01 to P60) and per pin (PIN01 to PIN30). Built by `python3 launch-kit/tools/build_post_images.py` from the post and pin files, so edit the words there, never the images.

- **Posts:** `slide-01.png`, `slide-02.png` and so on, 1080 x 1350. Carousels: upload the slides in order (Instagram carousel, TikTok photo mode). Video posts: the slides are the on-screen text, so upload them as a TikTok or Reels slideshow with the brand voiceover, or drop them into CapCut under the script.
- **Pins:** `pin.png`, 1000 x 1500.
- **`caption.txt`** in every folder: the caption and hashtags (pins: title, description, link and board).
- **`first-14-days.zip`:** everything for calendar days 1 to 14, in folders named by day and slot, for example `day-01-A-P01`.
- **`slide-text.txt`:** every word shown on the images (used for proofreading).

Fonts: the images use Liberation Sans (an Arial-style font), because the brand fonts could not be installed where the images were made. Colours and layout follow the brand guide.
